youtube-atc-stats

youtube-atc-stats は、YouTubeチャンネル「OD 航空管制解説」の運営者が、自分のチャンネルの統計を確認するための個人用の道具です。

YouTubeの公式API（YouTube Data API、YouTube Analytics API）を使い、視聴回数・再生時間・流入元などの統計を、閲覧専用の権限で取得します。動画の公開・変更・削除は行いません。

一般には提供していません。利用者は運営者本人だけです。

プライバシーポリシー

English

youtube-atc-stats is a personal tool used by the operator of the YouTube channel "OD 航空管制解説" to read statistics of their own channel through the official YouTube Data API and YouTube Analytics API with read-only access. It is not offered to the public.
